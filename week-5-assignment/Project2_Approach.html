Introduction

The objective of Project 2 is to work through importing, tidying and prepping messy data for downstream analysis using tidyr and dplyr. The following datasets have been chosen, stored as raw CSV files, and could be found in my Week 5 Assignment directory on GitHub:

  • Motherboard / Vice’s Car Thefts across the USA (Discussion source)

  • Medical records (Discussion source)

  • Highest Grossing Concert Tours by Women (Discussion source)

Approach

As per the project requirements, each of the datasets will follow the same steps separately:

  1. Import the raw CSV files from the GitHub directory to preserve the original or scrapped structure. If possible, I will mark any blank records as NA, where needed.

  2. Read the csv file and inspect the structure of the files, then try to get the headers / columns to store as variables.

  3. Reshape the datasets from a wide format into a long format using pivot_longer() , which will collapse the columns into rows. We can also drop any blank records here as well in this step, if missed with values_drop_na = TRUE.

  4. Cleaning and tidying the datasets will happen next, to standardize variable names (casing, naming patterns, turning Y -> Yes), convert column/row data types to the appropriate formats (ex. dates, numeric). I’ll double check once more for any missing or NA records to make sure that’s documented and accounted for prior to calculations.

  5. After, I can validate that the cleaned data is matching the unstructure data by verifying missing, duplicates or mislabeled variables are converted to the correct labeling.

  6. Lastly, I’ll explore the cleaned and validated data by creating some graphs and charts with ggplot2 for some simple analysis. Some questions I will have are how do Kia/Hyundai’s share of total vehicle thefts change over time, any corand adjusted vs actual gross for the tour.
